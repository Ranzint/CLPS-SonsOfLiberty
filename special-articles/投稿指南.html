SPECIAL / CONTRIBUTION GUIDE

本页为 CLPS Sons of Liberty 资料站的投稿说明。所有稿件均通过电子邮件提交与审核，不接受绕过审查的直接发布。

01 / 投稿邮箱

请将整理好的稿件与说明发送至下列邮箱。这是唯一的收稿渠道，站内私信、评论区留言均不视为正式投稿。

邮件正文请至少写清以下信息：

  • 署名或笔名，以及可以联系到你的方式；
  • 文章所属区号（例如 D1、D33），不确定的可以留空并说明；
  • 文章标题与一段简短的内容简介；
  • 素材来源说明：图片、音频、视频分别来自哪里，是否为本人原创。

文章请以 HTML 文件作为附件提交；图片等素材可一并打包，也可以先在正文中列出链接。请勿只发一张截图或一段纯文本，排版信息会在转交过程中丢失。

02 / 投稿流程

01整理稿件
02发送邮件
03内容审查
04上线发布

收稿后会先核对内容与素材，再确认排版与素材路径，最后并入站点发布。审查结果、修改意见都会通过邮件回复；未通过的稿件会说明原因，而不是无声退回。

03 / 你可以自由编辑 HTML 与 CSS

本站鼓励投稿者自己完成页面编排。标题层级、段落、列表、表格、图片、折叠区块、自定义配色与版式，都可以在稿件中自由使用，不必迁就默认样式。

项目说明
HTML 结构可自由使用语义化标签组织正文，标题层级请保持清晰。
CSS 样式可随稿附上自定义样式：配色、字号、间距、边框、动效均可提出。
JavaScript不接受。站点的文章渲染器会移除脚本，交互效果请改用纯 CSS 实现。
外链资源字体、图片、播放器等外部资源需在邮件中注明来源，并确保可以公开访问。
重要：站点的文章渲染器会过滤 style 标签、内联样式与脚本。你在本地写好的自定义 CSS 需要经过审查后并入站点样式表，才能正式生效——可以尽情写，实装要过审。

04 / 内容红线

以下内容一律不予受理，请在动笔前自行确认：

禁止内容范围
血腥、暴力、色情无论图文还是音频、视频形式均不接受；以音视频方式呈现的此类内容尤其禁止，包括暗示性画面、音效与链接。
政治内容任何形式的政治立场表达、时政评论、政治人物与事件影射、政治符号与标语。
社会热点社会争议事件、群体对立话题、煽动性言论，以及借热点进行的情绪化评论。
违法违规侵犯他人著作权、肖像权、隐私权的内容，以及违反法律法规的其他内容。

资料站只讨论架空世界观与站点设定本身。涉及现实议题的稿件，即使写作技巧出色，也会被整体退回。

05 / 必要的叮嘱

  • 先定区号。文章按区号归档，标题与区号请在邮件里写清楚，避免上线后反复改名。
  • 控制体积。单个文件请保持在 50 MB 以内。大体积视频不要直接提交，请提供可信平台的原始链接。
  • 素材要有出处。非原创图片、音频、字体请注明作者与授权方式；无法确认授权的素材请直接替换。
  • 保护隐私。正文、截图与素材中不要出现真实姓名、住址、证件号、聊天记录等个人信息。
  • 不要夹带推广。与文章无关的广告、导流链接、收款方式一律删除。
  • 一篇一稿。请勿把多篇文章塞进同一个文件，也不要在同一封邮件里混投无关内容。
  • 修改走原邮件。需要更新已发布文章时，请回复原投稿邮件并注明改动范围，方便对照审查。
  • 保留源文件。审查期间可能需要你重新导出或补充素材，请保留可编辑的原始文件。
提交前自查清单
  • 标题、区号、署名三项信息齐全，且彼此一致；
  • HTML 文件中没有脚本，也没有会被过滤的内联样式；
  • 所有图片、音频、视频均已注明来源，或为本人原创；
  • 全文不含血腥、色情、政治与社会热点内容；
  • 没有个人信息、广告与无关外链；
  • 文件体积在限制之内，附件可以正常打开。

06 / 关于审查

审查关注四件事：内容是否合规、叙述是否有依据、素材是否有授权、代码是否安全可读。审查不是对写作水平的评判，但合规章程没有例外，也不会因为稿件篇幅长、投入多而放宽。

请理解：提交稿件即表示你确认内容为原创或已获得授权，并同意站点在保留原意的前提下做必要的格式调整。若你不希望文章被修改，请在邮件中明确说明，我们会改为退回处理。

有疑问可以先发邮件询问，不必等整篇写完。说明你的构想与素材来源，我们会告诉你是否可行。
