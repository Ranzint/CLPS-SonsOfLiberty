## GitHub 是什么？

[GitHub](https://github.com) 是全球最大的基于 Git 的代码托管平台，由 Chris Wanstrath、PJ Hyett 和 Scott Chacon 于 2008 年创立。它为开发者提供了一个协作、分享和管理代码的云端空间。

## 核心功能

### 1. 仓库（Repository）
仓库是 GitHub 上最基本的单元，用于存放项目的所有文件和完整的修订历史。每个仓库都可以是公开的或私有的。

### 2. 版本控制（Git）
GitHub 建立在 Git 分布式版本控制系统之上，允许开发者：
- 追踪代码的每一次修改
- 随时回退到历史版本
- 在不同分支上并行开发

### 3. 协作开发
- **Pull Request**：开发者可以提交代码变更，请求项目维护者合并
- **Code Review**：团队成员可以互相审查代码，保证质量
- **Issues**：用于跟踪 Bug、功能需求和任务

### 4. Actions（CI/CD）
GitHub Actions 提供内置的持续集成和持续部署能力，可以自动化构建、测试和发布流程。

### 5. Pages
GitHub Pages 允许用户免费托管静态网站，常用于个人博客、项目文档展示。

## 为什么使用 GitHub？

- **开源生态**：成千上万的开源项目托管在 GitHub 上，是学习和贡献的宝库
- **社区活跃**：拥有数千万开发者用户，可以与全球同行交流合作
- **求职加分**：GitHub 个人主页已成为开发者简历的重要组成部分
- **免费使用**：公开仓库完全免费，私有仓库也有免费额度

## 快速上手

```bash
# 安装 Git 后配置用户信息
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

# 克隆一个仓库
git clone https://github.com/username/repository.git

# 提交你的修改
git add .
git commit -m "描述你做了什么"
git push origin main
```

## 总结

GitHub 不仅是一个代码托管工具，更是开发者社区的核心聚集地。无论你是初学者还是资深工程师，GitHub 都是学习、协作和展示自己的理想平台。
